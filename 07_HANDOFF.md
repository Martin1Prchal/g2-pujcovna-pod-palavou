# Handoff

## Finální výstupy
- Funkční lokální prototyp: `index.html`, `app.js`, `styles.css`, `data.mjs`.
- Sedm veřejných stránek a lokální prototype admin.
- Automatické testy a projektová dokumentace.

## Veřejné odkazy
- GitHub repozitář: https://github.com/Martin1Prchal/g2-pujcovna-pod-palavou
- GitHub Pages: https://martin1prchal.github.io/g2-pujcovna-pod-palavou/

## Bezpečné instrukce k přístupům
Projekt neobsahuje credentials ani externí účty.

## Omezení
Prototype admin ukládá změny jen do konkrétního prohlížeče. Formuláře nic neposílají mimo zařízení. Výletové metriky a vybrané ceny je před produkcí potřeba znovu potvrdit.

## Co má příjemce vědět
Spuštění: `npm start`. Admin je dostupný ze zápatí; demo heslo `palava`. Aktuální `main` se publikuje přes GitHub Pages. Výsledek je připravený pro navazující postup Figma → Framer.
