# Projektová pravidla pro Codex

- Před větším zásahem ověř skutečný stav relevantní části projektu.
- Zachovej fungující části a prováděj pouze změny potřebné pro zadání.
- Nepřidávej technologie, knihovny ani služby bez jasného důvodu; placené služby vyžadují souhlas.
- Po významné práci aktualizuj `03_CHECKLIST.md` a `05_STATUS.md`.
- Důležitá rozhodnutí a jejich důvody zapisuj do `04_DECISIONS.md`.
- Změny přiměřeně testuj a výsledky zapisuj do `06_QA.md`.
- Dokumentace musí odpovídat reálnému stavu projektu.
- Credentials, secrets ani `.env` nikdy neukládej do repozitáře ani veřejných výstupů.
- Před produkčním nasazením, placenou nebo nevratnou operací vyžádej souhlas.
- Jde výhradně o lokální funkční prototyp; neprováděj produkční nasazení.
