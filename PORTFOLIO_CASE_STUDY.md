# Půjčovna kol pod Pálavou
## Redesign webu a responzivní prototyp

### 1. Kontext

Projekt vznikl jako redesign webu lokální půjčovny kol pod Pálavou. Cílem bylo zpřehlednit nabídku kol a příslušenství, lépe prezentovat ceník, zvýraznit tipy na výlety, galerii a kontakt a doplnit srozumitelnou nezávaznou poptávku.

### 2. Moje role

Navrhl jsem strukturu webu a UX/UI jednotlivých stránek, připravil responzivní coded prototyp, převedl návrh do Figmy a následně sestavil a doladil finální variantu ve Frameru. Součástí práce byl návrh editovatelného obsahu a CMS vazeb, průběžné QA a cílené úpravy desktopové, tabletové a mobilní verze. AI jsem používal jako nástroj pro rychlejší implementaci, kontrolu konzistence a řešení konkrétních technických problémů.

### 3. Workflow

1. Návrh struktury a vizuálního směru
2. Coded funkční prototyp
3. Převod obrazovek a komponent do Figmy
4. Implementace ve Frameru
5. Responzivní úpravy pro desktop, tablet a mobil
6. Finální vizuální a funkční QA

Coded verze sloužila jako hlavní vizuální a funkční reference pro pozdější implementaci ve Figmě a Frameru. Díky tomu bylo možné porovnávat strukturu, obsah i chování napříč všemi třemi verzemi.

### 4. Hlavní části webu

- Homepage
- Půjčovna
- Ceník
- Výlety
- Galerie
- Kontakt
- Poptávka

### 5. Zajímavé řešené problémy

- konzistentní responzivní chování na desktopu, tabletu a mobilu
- editovatelný obsah a CMS vazby
- odstranění mobilního overflow a korektní zalamování textu
- horizontálně scrollovatelné filtry na malých obrazovkách
- filtrování výletů a galerie
- galerie s lightboxem
- formulář s dynamickou logikou
- podmíněné zadávání hmotnosti od výšky 180 cm
- rozdílné řešení hero sekce homepage a vnitřních stránek
- přesná synchronizace coded site → Figma → Framer

### 6. Nástroje

- Figma
- Framer
- HTML, CSS a JavaScript
- Node.js
- Git a GitHub
- AI / ChatGPT / Codex

### 7. Výsledek

Výsledkem je responzivní vícestránkový web dostupný jako coded varianta, Figma design a publikovaná Framer implementace. Projekt zahrnuje editovatelný obsah tam, kde byl navržen, mobilní verzi a ukázkový poptávkový workflow. Poptávka je portfolio/demo implementace a není napojená na produkční SMS ani backendový systém.
